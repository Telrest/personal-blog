# 设计的秘密

一座可以亲手操作的原理展馆：拆开一个东西，改变一个条件，看见它为什么这样工作。

大学网站作业。中文界面，沿用 Telrest 博客的森林配色、深浅色偏好、胶囊按钮和彩虹悬停光边，模型是视觉中心。

The exhibit shares the blog’s forest palette, saved light/dark preference, pill controls, and rainbow hover edges.

### 01 按动圆珠笔的秘密（模块 A）


原型：**ZEBRA SARASA CLIP JJ15 0.5**（按动式凝胶墨水笔）。外观比例按官方名义尺寸，
内部是**简化教学机构**，不是 JJ15 的实物凸轮。

- 机构：按帽／按杆 → 转子（3 凸耳，相隔 120°）→ 固定导向（6 个索引位置，60° 交替深浅）→ 笔芯；前端一根复位弹簧。
- 一次完整按压释放推进 **60°**（按下 30° ＋ 释放 30°）；深导槽 → 收芯，浅锁止位 → 出芯；两次按动状态复原。
- 状态变量与派生量：`x`（机构位移 0 → 4.8 mm）、`θ`（索引角）、`cycle`（已完成循环）、
  阶段（pressing / indexing / releasing / settling / aborting）。3D、展开图、读数、字幕共用一份状态。
- 直接操作：**拖动按帽**沿轴按压；按到 4.8 mm 才提交，没按到底就松手会原路退回、状态不变。
- 查看方式：外观 / 剖视 / 拆解；预设视角：整笔 / 机构特写 / 剖切正视 / 拆解位。
- 教学说明只出现在页面底部一处，不逐按钮重复免责声明。

### 02 变速的秘密（模块 C）


外观参考 **GIANT Talon 0**（2025 英国版 M 码 29 英寸），变速结构参考 **Shimano Deore M6100 1×12**：
单前盘 30T + 12 片飞轮 10–51T + 机械后拨。计算公式、链长求解、参考出处见
[变速器模型说明](docs/derailleur-model.md)。

- 稳态传动：齿比、后轮转速、理论车速、理想轮端力矩、输入/输出功率，全部由 `model.ts` 一处算出。
  「固定踏频」与「固定输入力矩」是两个分开的比较模式，页面上写明各自保持什么条件。
- 链条是一条**闭合链环**：前盘 → 下段 → 张力轮 → 导向轮 → 飞轮 → 上段。切线靠「枚举 + 排自交 + 取最短」
  定出来；**12 个挡位共用同一条 120 节（1524 mm）链条**，摆臂角由链长方程解出（误差 3e−7 mm 量级）。
- 后拨：平行四边形（连杆 45 mm、铰距 28 mm）让导向轮沿圆弧横移对齐齿片；摆臂绕导向轮转，收放链条余量。
  导向轮负责「送到哪一片」，张力轮与摆臂负责「收放多少链条」，页面分开讲。
- 换挡过渡是三步：后拨先把导向轮推到目标齿片平面 → 链条抬过齿顶跨过去 → 落进新齿片齿谷（链长始终守恒，跨越时逐帧重解摆臂角）。
- 交互：换轻挡/换重挡（带齿数）、12 片直接点选、踏频 0–120（滑块与数字框同步）、输入力矩 5–60、
  驱动 / 滑行（单向离合脱开）、暂停 / 慢放 / 重置、五个预设镜头、显示开关、零件点选讲解。
- 区分**目标挡位**与**已完成啮合的挡位**：停踩时请求排队，链条转起来才执行；过渡标注为示意。
- 旁观者模式：指针锁定 + WASD 自由飞行（点击画面锁定鼠标，Esc 退出）；**滚轮换挡**（上滚换轻挡、下滚换重挡），方便边飞边看换挡；**进入全屏会自动切到旁观者模式**。
- 彩蛋：前轮可以用鼠标拨动旋转，不给任何提示，也不影响传动与读数。

### 03 GPA 的秘密（模块 B）


不依赖任何具体学校的教务系统，用**可替换的绩点规则配置**计算。默认预设是北航本科换算公式
（`0≤s<60` 记 0；`60≤s≤100` 用 `4 − 3(100−s)²/1600`），页面上写明来源与适用范围，不宣称通用。

- 纯二维：学分权重（100% 分段条）、当前贡献（q_i 堆叠到 GPA，**0–4 固定标尺**）、提分实验、满绩差距。
- 计算全部在 `src/exhibits/gpa/model.ts` 里，页面、图表、解释共用同一个结果对象；中间精度不舍入。
- 课程可增删、可填小数学分、可不参与计算；成绩与假设成绩都有文本框与滑块双向同步；空成绩与 0 分严格区分。
- 本地保存（localStorage）、JSON 导入导出；导入失败保留原数据并说明原因；不上传任何课程数据。
- 「带我看懂」用独立的三门课示例讲权重与曲线，不读写用户保存的课程。

### 04 骨骼的秘密


右足小趾（第 5 趾）**近节趾骨基底部**的交互科普展品。整足骨格使用
**BodyParts3D**（DBCLS，CC BY 4.0）的右足 26 块真实骨模型；骨折形态、受力与修复过程
都是通用教学示意，部位与侧别来自用户提供的报告摘录（不含影像与身份信息）。
依据、坐标系与边界见 [骨骼模型说明](docs/bone-model.md)。

- 三个页签：**结构与断端** / **受力示意** / **通用修复**；三个页签各自保存参数，
  切换页签会切到该页签的默认镜头。
- 结构与断端：整足 → 「找到骨折位置」平滑靠近第 5 趾列；目标骨橙红、第 5 跖骨灰蓝对照；
  裂面用**同一张细分网格 + 同一个切面**切成两片（零位移时两片断面完全贴合，可点「拖到零位移」验证）；
  裂隙 / 横移 / 旋转是三个独立参数；剖切可看皮质环与松质骨（示意）。
- 受力示意：轴向 / 侧向 / 外展三个方向，λ 为归一化载荷（只显示 0–100%，不是牛顿）；
  完整对照与预制骨折是两套几何，形变夸张显示（≤3° / ≤0.8°），不计算断裂阈值与承重。
- 通用修复：独立对位场景 + 血肿 / 软骨痂 / 骨性骨痂 / 重塑四阶段；阶段按钮为主控，
  进度可拖动、暂停、重置；进度不是天数、愈合率或承重能力。
- 旋转模型后侧别标注不会翻面；「回到默认视角」是唯一的镜头回正来源。
- 无 WebGL 时给出结构图、受力图、四阶段图与同等核心解释。

### 05 航空发动机的秘密

通用双转子、分流排气涡扇的**教学模型**，不对应任何实际发动机型号；比例沿用公开参考模型的米制几何，
但各项数值都是标明假设的示意，不宣称真实尺寸或型号性能。依据与改造过程见
[发动机模型说明](docs/engine-model.md)。

- 双轴：风扇、低压压气机与低压涡轮同轴（内轴），高压压气机与高压涡轮同轴（中空外轴）；两轴各自被自己的涡轮驱动，转速互不相绑。
- 路径：风扇后气流分成外涵道与内涵道两路，核心机里再经燃烧室加热、由两路喷口分别排出；静子叶片不加入任何转动组。
- 来源：Grab3D 的 CC0 剖切模型拆成风扇／低压压气机／高压压气机／高压涡轮／低压涡轮五个轴向组件，
  轴、机匣、环形燃烧室、喷口与互动逻辑在网页端重建。
  速度、响应与总温总压趋势是标明的示意，不当作型号性能数据。

### 番外 · 魔丸模式（独立游戏入口）

「为了绩点，我把航空发动机装上了自行车。」入口 `#/game`，页头导航「魔丸模式」。

把 02 变速、03 GPA、04 骨骼、05 发动机四件展品拼成一款第三人称无尽躲避游戏：
自动前进、连续左右转向，躲开一排排低矮的蓝色「连跳矮墙」（混凝土墙 + 压顶，墙与墙之间留缺口）；撞一次就结束。
计分是「满绩渐近线」：前 1 000 m 从 0 涨到 3.9，之后每 500 m 多一个 9，永远小于 4.0，
超过六个 9 显示 `3.999999…` 并注明第几个 9。开始处的门楼按北航「体能锻炼走廊」实拍照片
重建成三维示意，摔车演出里的 X 光片用的是骨骼展品同一份 GLB 资产。

它**单独加载、单独成页**，不替换任何原理展品，也不影响展馆的科普功能。
设计取舍、公平性算法、验证与限制见 [魔丸模式说明](docs/mowan-mode.md)。

## 快速开始

```bash
npm install
npm run dev       # http://127.0.0.1:5183
npm run build     # tsc --noEmit && vite build → dist/
npm run preview   # 预览 dist
npm test          # vitest 单元测试
```

路由使用 HashRouter（`#/exhibit/pen`），`dist/` 可以直接放静态托管，不需要 URL 重写规则。
`dist/` 必须用静态服务器打开：直接双击 `index.html` 会因为 ES module 与 `crossorigin` 被拦下。

## 约定（项目硬规则）

1. **模型状态唯一**：每件展品只有一个状态源，3D、图表、读数、文字标签全部从它派生。
2. **四层分离**：model（计算/状态机，不 import three.js）→ geometry → controls → content。
3. **锁止与历史用状态机**：不用一条时间变量硬凑。
4. **不编造参数**：每个数值带来源标签；找不到出处就不显示。
5. **镜头归用户**：用户动过镜头后不自动回正，只有用户点「回到默认视角」才回。
6. **离场即释放**：停止帧循环，dispose 几何体/材质/贴图/渲染器。
7. **3D 不可用给图文替代**，不给黑屏。
8. **控制必须有文字标签**，状态用文字写出来，颜色只是辅助。

## 已知问题

- 02 仍是「制作中」，没有任何可操作模型（01、03、04、05 已开放）。
- 骨骼展品的断面、剖切面与髓腔桥接是示意补充：来源模型是表面网格，没有真实皮质内层与髓腔。
- 骨骼展品的形变经过夸张显示（≤3° / 片段 ≤0.8°），不计算应力、断裂阈值或承重能力。
- 骨骼展品的图文替代（无 WebGL 路径）是单独渲染检查的，没有在真正禁用 WebGL 的浏览器里走完整流程。
- 变速器的齿形、链节相位、四连杆铰点、齿片间距、导轮中心距都是教学设定，不是厂家尺寸；
  换挡过渡是示意运动学，没有齿面接触与受力求解。
- 变速器的「旁观者模式」主路径依赖指针锁定：受限容器里浏览器会拒绝，这时退回「按住拖动环顾」，
  WASD 仍然可用。
- 变速器窄屏只检查了布局与控件可读，没有在手机上做触摸拖动/缩放测试。
- 按动笔的内部机构是教学设定：齿形、索引数、行程、弹簧尺寸都可统一调整，不是实测凸轮。
- 页面不显示按压力：没有可靠的按压力数据，只给弹簧长度与压缩量。
- 笔夹抬起是独立演示，不影响锁止（资料包未确认 JJ15 有「开夹自动收芯」功能，因此不做）。
- 窄屏（500 px 宽）已检查布局与按动、以及变速器的单列布局；没有在真机上做长时间性能测试。
- 魔丸模式是番外游戏：门楼、发动机、车架都是示意模型，门楼尺寸按照片比例目测、不是实测；
  闸机只铺路面外侧（不占用行车线），也不参与碰撞；首版没有跳跃、飞行、联机、换挡，
  按动圆珠笔的车把启动键彩蛋留到下一版；开场背景照待补，现在开场用的是实时三维跑道与门楼。
  详细限制见 [魔丸模式说明](docs/mowan-mode.md)。
- 在受限沙箱里跑 `npm run dev` / `npm test` 可能报 `spawn EPERM`：Vite 在 Windows 上会同步
  调用 `net use` 探测磁盘映射，被沙箱拦下。普通终端里运行不受影响。

## 同步博客构建 / Sync the blog bundle

在博客根目录运行 `npm run build:design`，会先检查并构建设计实验，成功后再替换 `public/lab/design/` 的生成文件。源文件保存在 `lab-src/design/`；不要直接编辑压缩产物。

Run `npm run build:design` from the blog root. It checks and builds the experiment before replacing its generated public bundle. Edit the source in `lab-src/design/`, not the compressed files.
