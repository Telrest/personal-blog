## 3. 坐标与尺度

模型（GLB）坐标：米；**−X 外侧（小趾侧）、+Y 足背、+Z 足趾**。

展台坐标通过 `root` 上一次旋转 + 缩放得到：

```
展台 (x, y, z) = (−glbX, glbZ, glbY) × 20      // SCENE_SCALE = 20，即 1 展台单位 = 50 mm
```

- 这一次变换是**纯旋转 + 等比缩放**，行列式为 +1（右手系不变）→ 不会镜像左右；
- 缩放只换单位，不改变骨与骨之间的比例（保留来源比例，不按旧任务书的 18 mm 重设）；
- 旋转后「足背视图」：足跟在下、足趾在上、**拇趾在左、小趾在右**；
- 内侧 / 外侧 / 右足 的标注挂在模型锚点上，转动镜头不会翻面。

## 4. 目标骨与预制裂面

### 4.1 目标骨

- 长轴由来源模型的几何提示给出：基底 ≈ `(−0.0407, −0.0321, 0.0214)` m，
  远端 ≈ `(−0.0539, −0.0335, 0.0436)` m，长轴约 **25.85 mm**（保留来源比例）。
- 显示前对目标骨做一级 **Loop 细分**（406 → 1624 三角面），只为让关节端与断面
  看不出大块三角面；不增加任何解剖细节。

### 4.2 裂面（预制几何）

| 参数 | 值 | 性质 |
| --- | --- | --- |
| 位置 | 从基底沿长轴 **18%**（约 4.65 mm） | 教学设定 |
| 法线与骨长轴夹角 | **20°**（朝足背侧倾斜） | 教学设定 |
| 断面微观起伏 | ±0.05 mm，只与断面内位置有关 | 固定种子、确定性 |

裂面两侧由**同一张细分网格 + 同一个平面 + 同一条起伏函数**切开：
每一对相邻三角面在切面上的交点用同一公式计算，因此零位移时两片断面完全贴合。
页面上有「对齐两片骨」按钮，可以直接把三个参数归零验证。

### 4.3 断端姿态

| 参数 | 默认 | 可探索范围 |
| --- | --- | --- |
| 裂隙（沿骨轴） | 0.6 mm | 0 – 2.5 mm |
| 横移（外侧） | 1 mm | 0 – 3 mm |
| 旋转（向外侧偏） | 8° | −15° – +15° |

远端片段的刚体变换（枢轴取裂面中心）：

```
p' = R(θ)·(p − pivot) + pivot + (axis·gap + (−X)·offset)
```

- 零姿态是严格恒等变换（单测断言坐标误差 < 1e-12）；
- 旋转与平移都作用在远端片段组，中节与末节趾骨位于独立可见组，骨折时同步远端变换，一起移动；
  第 5 跖骨固定在足部一侧 → 不会「整根小脚趾散开」；
- 「恢复演示姿态」= 回到上面的默认演示值，不是复位指导。

### 4.4 断面封口

断面由外轮廓向内做等距偏移得到 **皮质环（约 0.8 mm）** 与 **松质核心**；
核心使用固定种子的程序化纹理（canvas 生成，无外部贴图）。
零位移时两张封口面贴合、藏在实体内部，此时不渲染，避免两张面重合闪烁。

## 5. 剖切（皮质与内部）

- 剖切平面：**包含骨长轴的纵向平面**，法线为「与骨长轴正交的足背方向」；
- 保留足底一侧（three.js 保留裁剪平面法线正侧），从足背看进去是断面；
- 裁剪平面在材质上必须用**世界坐标**（three.js 语义），代码里分别乘完整骨／各片段的 `matrixWorld` 再挂到各自材质；
- 断面轮廓由「骨片表面与剖切平面求交」得到，串成环后封口（皮质环 + 松质核心）；
- 源模型是**表面网格**，没有真实髓腔与皮质内层：剖面是按教学需要补的示意结构，
  页面上明确写了这一点。

## 6. 受力示意

- 载荷用**归一化 λ（0–1）**，页面只显示百分比，不显示牛顿、公斤或任何承重值；
- 三种方向（作用点与约束相同、方向不同）：

| 方向 | 施力位置与方向 | 约束 | 示意形变上限（λ=1） |
| --- | --- | --- | --- |
| 轴向 | 趾尖沿骨轴压向基底 | 足部其余部分（第 5 跖趾关节一侧） | 压缩 0.35 mm |
| 侧向 | 从外侧压向趾骨中段 | 同上 | 中节/末节相对近节弯曲 3° |
| 外展 | 在趾尖向外侧拉 | 同上 | 整根趾在关节处外摆 3° |

- 完整对照与预制骨折是**两套几何**，各自只取自己那一项、不叠加：
  预制骨折时只让远端片段相对基底轻微错动（≤0.8°）；
- 画面形变是**夸张显示**，页面写明「形变已夸张显示」与上限；
- 不计算应力、不做有限元、不判断任何人的受伤机制或疼痛。

## 7. 修复（通用四阶段）

- **独立对位场景**：与「结构与断端」页可调的断端参数分开保存，播放进度不会把
  结构页的移位骨块自动吸回原位；
- 四阶段与进度区间（只用于导演节奏）：血肿 0–0.2 / 软骨痂 0.2–0.5 /
  骨性骨痂 0.5–0.8 / 重塑 0.8–1；
- 组织可见度曲线（`repairAppearance`）：血肿在 0.16–0.30 淡出；软骨痂 0.16–0.3 出现、
  0.18–0.44 长大、0.46–0.62 淡出；骨性骨痂 0.46–0.62 出现、0.48–0.68 长大；
  0.80–0.97 缩小并逐渐并回骨本色；
- 骨痂几何：以裂面处的骨横截面为基准，沿骨轴做「纺锤形外扩」的放样曲面
  （`callusOutgrowth = 2 mm`，沿轴半长不超过 9 mm，且不超过裂面到基底距离的 85%）；外扩量在两端收进骨内，避免浮在表面外；
  尺寸由射线法测得的骨表面半径 + 轮廓函数得到，构建时算一次、之后只更新顶点位置；
- 剖开观察时另有一条髓腔内桥接示意（`bridge`），只在剖切状态显示；
- 页面写明：进度不是天数、不是愈合率、不是承重能力；动画走完不代表可以运动或停止治疗；
  真实过程各阶段重叠、因人而异。

## 8. 状态与分层

```
src/exhibits/bone/
  model.ts        纯逻辑：坐标换算、裂面、断端变换、λ 形变、修复曲线（不 import three）
  model.test.ts   26 条：骨数/目标骨/裂面角度/零位移/夹取范围/λ 线性/阶段边界
  mesh.ts         网格工具：合并顶点、Loop 细分、平面切分与封口、剖面求交、耳切三角化
  mesh.test.ts    10 条：切分、断面、起伏确定性、开链成环、细分面数与包围盒
  geometry.ts     三维层：加载 GLB、分组、裂面切分、剖切面、箭头、骨痂、拾取
  scene.ts        舞台层：镜头预设、拾取、标注投影、释放
  state.ts        状态层：三个页签各自的状态 + 修复进度时钟（暂停/播放/速度）
  content.ts      文案、图例、资料出处、模型边界、带我看懂的步骤
  controls.tsx    三个页签各自的控制面板（只写回状态）
  diagrams.tsx    无 WebGL 时的结构图 / 受力图 / 阶段图（与状态同源）
  index.tsx       组合：状态 → 舞台 / 面板 / 标注 / 说明
```

- **唯一状态源**：`state.ts` 的 store 保存三个页签各自的参数；3D、图例、读数、标注
  都从它派生。修复进度是唯一随时间推进的量，由独立时钟持有（不与力学计算混在一起）；默认暂停，只在修复页播放时推进。
- **页签切换**会换到该页签的默认镜头（三个页签看的尺度不同）；页内用户转动镜头后，
  代码不再自动回正，只有「回到默认视角」按钮会。
- 离场释放：`ModelStage` 卸载时停止帧循环，`dispose()` 释放几何/材质/贴图/渲染器。

## 10. 未实现 / 未验证

- **软组织、韧带、肌腱、内固定器材**：没有建模，页面在「没有做的事」里写明。
- **髓腔与真实皮质内层**：源模型是表面网格，剖切面与髓腔桥接是示意补充。
- **断面的真实骨小梁结构**：断面纹理是程序化示意，不是影像或组织学表现。
- **真实无 WebGL 环境**：图文替代已单独渲染验证，但没有在真正禁用 WebGL 的浏览器里
  走完整流程（见验证记录）。
- **真机与低端显卡**：只在桌面 Chromium 与 500 px 窄屏下检查，未做长时间性能测试。
- **资料包给出的阶段时间窗**（数小时血肿、约 48 小时软骨痂、数周骨性骨痂）只在文档里
  作为教材背景提及，**不**用于映射进度条。
