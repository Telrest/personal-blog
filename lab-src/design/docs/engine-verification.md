# 发动机展品验收记录

日期：2026-11-01。定位：通用双转子、分流排气涡扇教学模型。

## 自动验证

- `npm test`：全项目测试通过；发动机专用测试 12 项。
- `npm run build`：TypeScript 检查与生产构建通过。
- `python src/exhibits/engine/verify_asset.py public/engine/rotors.glb`：五个独立转子节点、17,396 个三角面、索引范围、有限数值、内嵌贴图与许可信息校验通过。
- 发动机测试覆盖：指数响应与累计转角在大步长和不规则步长下的一致性、暂停、无效步长、重置订阅、双轴组件映射、五档工况的总温总压趋势、同轴间隙、两路气流边界以及生成几何的有限数值。

## 实际浏览器检查

本地预览：`http://127.0.0.1:5183/#/exhibit/engine`。

- 桌面 1440×1000：检查整机、纵向剖视、拆解、压气机/燃烧室特写、两根轴与分别隔离的高低压系统；逐步走完六步导览。
- 390×844 窄屏：页面内容宽 375px，无横向溢出，341px 展台可容纳侧面整机；控件和说明竖向排列。
- 调节至高工况后两轴分别响应；暂停前后模型时间和两轴累计转角完全相同，镜头控制继续保留。
- 拆解时冻结机构；恢复装配后恢复先前播放状态。预设镜头切换和自由观察均可操作。
- 标准画质与轻量画质均实际查看。当前浏览器样本中，标准气流视图约 154 次绘制、269,926 个渲染三角面（含阴影），轻量约 86 次、136,326 个；两者采样约 165 fps。该结果只描述本机当前预览，不代表手机硬件性能承诺。
- 页面离开后重新进入，模型重新装载；控制状态正常，没有残留画布或浏览器控制台错误。

## 资源生命周期

沿用展馆的唯一动画时钟与展台。场景离开时注销订阅和事件、释放实例、几何、材质、贴图及展台上下文；异步装载取消时同样释放已取得资源。资源释放经代码路径检查和页面往返检查，未进行长时间 GPU 内存压力测试。

## 已知边界

- 现成 CC0 转子几何经过拆分改造；并非某个实际发动机的精密 CAD。省略详细轴承、密封、冷却与附件。
- 展示级数、尺寸比例、速度和响应常数为教学设置。工况低端为怠速端，不模拟完整启动或停机。
- 总温/总压为相对趋势，粒子为几何路径；没有 CFD、循环匹配、推力、油耗或效率预测。
- 拆解为教学布局，不代表维修程序。不含加力、故障和喘振。
- 无 WebGL 时提供图文替代；该分支经代码检查，本次未强制关闭浏览器 GPU 进行实机验收。
- 未在真实手机硬件或多种浏览器上进行性能测试。

来源、模型改造方法与参数表见 `engine-model.md`。
