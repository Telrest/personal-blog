# 航空发动机：模型依据与简化边界

## 定位

通用双转子、分流排气涡扇教学展品，不对应某个实际发动机型号。X 正方向为气流方向，Y 向上，轴心 Y=Z=0。比例沿用参考模型的米制几何，但不宣称为真实产品尺寸。

## 可追溯的结构事实

| 关系 | 模型实现 | 依据 |
| --- | --- | --- |
| 风扇后的空气分流 | 核心与外涵道各有独立路径 | NASA Turbofan Thrust |
| 低压轴系 | 风扇、低压压气机、低压涡轮、内轴 | NASA 双转子说明 |
| 高压轴系 | 高压压气机、高压涡轮、中空外轴 | 同上 |
| 固定叶片 | 静子实例不加入任何转动组 | NASA Compressors |
| 环形燃烧室 | 内外衬壁位于轴外，留中心通道 | NASA Combustor |
| 燃烧加热并有总压损失 | 模型站点趋势约束 | NASA Combustor |
| 两路分别排气 | 外侧喷口与更靠后的核心喷口 | NASA Nozzles |

## 现成模型的选择与改造

选用 Grab3D 的 Turbofan Jet Engine Cutaway：
https://grab3d.com/models/vehicles/jet-engine/

该资源附带 CC0 1.0 许可和 origin/AI disclosure：几何由 Blender 程序生成，生成脚本由 AI 辅助编写。网站展示保留来源与简化说明。

原始模型仅有 body 和 rotor 两组，所有转动件与一根示意轴合并。没有将其直接当成双转子模型使用。

改造步骤：
1. 从 rotor 中提取风扇、低压压气机、高压压气机、高压涡轮、低压涡轮五个轴向组件。
2. 保留原有叶片形状、UV 和 PBR 贴图；删除原共用示意轴的 240 个三角面。
3. 统一为气流 +X、轴心 Y=Z=0，导出五个独立节点，共 17,396 个三角面，约 1.42 MB。
4. 网页端重建内侧低压轴、中空高压轴、固定叶片、机匣、环形燃烧室、喷口、展示支架和互动逻辑，并补全随低压转子转动的风扇整流锥。
5. 原始 body 没有作为可运行的整机直接使用。

许可副本：`public/engine/LICENSE.txt`。导出文件内含来源、许可与改造记录。

复现（脚本仅使用 Python 标准库）：
```text
python src/exhibits/engine/adapt_model.py original.glb public/engine/rotors.glb
python src/exhibits/engine/verify_asset.py public/engine/rotors.glb
```
原文件下载地址：https://grab3d.com/dl/jet-engine/jet-engine.glb

## 教学参数

所有教学参数集中在 `model.ts` 的 ENGINE。展示级数为风扇 1、低压压气机 3、高压压气机 5、高压涡轮 1、低压涡轮 3，来自选用的教学几何，不是厂家规格。

| 参数 | 设定 | 属性 |
| --- | --- | --- |
| 初始工况 | 0.38 | 教学输入，不是推力百分比 |
| 工况范围 | 0 到 1，低端表示怠速端 | 不模拟停机或完整启动 |
| 低压响应时间常数 | 1.6 模型秒 | 一阶教学响应，不来自转子惯量 |
| 高压响应时间常数 | 0.85 模型秒 | 同上 |
| 低压示意频率 | 0.12 + 0.66 × 低压状态 | 圈/模型秒，不是实机转速 |
| 高压示意频率 | 0.24 + 1.05 × 高压状态 | 同上 |
| 低压轴 | 半径 0.055，X=-1.09 到 1.27 | 教学结构比例 |
| 高压中空轴 | 内半径 0.078、外半径 0.108，X=-0.34 到 0.84 | 保留同轴间隙 |
| 观察速度 | 0.1、0.25、0.5、1 倍 | 改变模型时间推进，不修改工况 |

速度响应和累计转角均用指数响应的闭式积分。大时间步与不规则细分步得到相同结果；不依靠采样到某一帧完成事件。

## 相对温压图

总压、总温是两条独立归一化曲线。计算表达教学方向，不是一维循环或部件匹配求解。

- 压气机总压、总温上升。
- 燃烧室总温上升，总压下降。
- 涡轮总温、总压下降。
- 喷口示意总温保持不变，总压计入小损失。
- 不将总量曲线称为静压、静温或气流速度。
- 不计算推力、燃油流量、热效率、真实 N1/N2 或认证性能。

## 几何与交互边界

- 风扇与主要转子采用上述 CC0 教学几何，静子使用可扭转的程序化翼形。
- 机匣采用带壁厚的纵向四分之一剖切，不是精密制造截面。
- 双轴和组件隔离是教学观察手段；省略详细轴承、密封、附件和冷却气路。
- 气流路径为确定性几何轨迹，不模拟叶间接触和真实流场。粒子数量与速度不是密度、质量流量或实际速度。
- 燃烧效果仅位于环形区域，不代表燃烧求解。没有加力或喷口尾焰。
- 拆解将外壳抬起并沿轴分离组件，冻结机构；布局不是维修拆装顺序。
- 暂停冻结模型时间、双轴转角和粒子进度；镜头仍可移动。
- 轻量画质关闭阴影，降低 DPR 和粒子数。离开页面释放网格、贴图、实例资源与渲染上下文。
