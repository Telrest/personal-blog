# 魔丸模式（独立游戏入口）

> 「为了绩点，我把航空发动机装上了自行车。」
>
> 入口：`#/game`（页头导航「魔丸模式」，首页也有一张入口卡）。

这是展馆的**番外**，不是第六件展品：它把 05 自行车、02 发动机、04 GPA、03 骨折四件东西
拼成一款第三人称无尽躲避游戏。它单独加载、单独成页，不替换任何原理展品，也不影响展馆的科普功能。

---

## 一、玩法与操作

| 项目 | 说明 |
| --- | --- |
| 前进 | 车辆自动前进，玩家只控制**连续左右转向**（不是分车道跳格） |
| 电脑 | `A` / `D` 或 `←` / `→` 转向；`空格` 短时冲刺；`Esc` 暂停；`Enter` 开始 / 再来一次 |
| 手机 | 左下「左 / 右」触控按钮、右下「冲刺」、右上「暂停」 |
| 冲刺 | 提高车速（距离涨得更快），同时障碍来得更急；余量有限、会缓慢恢复 |
| 旁观 | 暂停菜单里进入：指针锁定 + `WASD` 自由飞，`Q/E` 升降，`Shift` 加速，`Esc` 退出 |

车身表现：转向时车身倾斜、前轮转动；车轮 → 曲柄 → 链条按同一份车速联动；
发动机风扇随车速转，冲刺时尾焰拉长。

首版**没有**跳跃、飞行、联机与换挡。

## 二、「满绩渐近线」计分

分数名固定为**魔丸 GPA**，与任何真实课程 GPA 无关。

| 距离 | 显示 | 9 的个数 |
| --- | --- | --- |
| 0 → 1 000 m | 0.00 → 3.89 线性 | — |
| 1 000 m | 3.9 | 1 |
| 1 500 m | 3.99 | 2 |
| 2 000 m | 3.999 | 3 |
| 2 500 m | 3.9999 | 4 |

- 前 1 000 m 线性；之后每 500 m 多一个 9。数学上 `G = 4 − 10^(−n)`，永远小于 4。
- **实现不用浮点小数**：`n = 1 + floor((d − 1000) / 500)`，显示字符串由 `'9'.repeat(n)` 拼出。
  因此骑到 `1×10^12 m` 也不会因为精度舍入成 4.0（单测覆盖到 `1e16`）。
- 线性段的小数位**截断不进位**：999.9 m 显示 3.89，3.90 只在 1 000 m 出现。
- 超过六个 9 时显示 `3.999999…`，同时注明「第 N 个 9」。
- 每拿到一个新 9：短音效 + 数字弹出动画 + 节点门牌。
- 历史纪录**按实际距离**比较：1 480 m 与 1 499 m 都显示 3.99，后者才是更好的成绩。

距离参数全部集中在 `src/game/config.ts` 的 `CONFIG.score`，改完刷新即可试玩。

## 三、障碍与公平性

首版障碍只有一种「连跳矮墙」：低矮的蓝色混凝土墙（高 0.85 m、厚 0.38 m，顶部压顶，墙脚一道深色风化带），长度按那一排被挡住的宽度来，一排可能是一到三段墙，墙与墙之间就是通道。难度随距离上升，但车速设了上限（33 m/s），
后期靠「一排多带 + 通道变窄」增加挑战。

每一排生成时都要过一道**可达性检查**：

1. 上一排算出「玩家可能待在哪」的区间集合；
2. 按当前车速与横向能力（`maxLateralSpeed`）算出两排之间的时间能横移多远（打 0.9 折）；
3. 与这一排的净通道取交集；交集为空就换一种排法重来；
4. 试 18 种仍不行，就退化成一排「正对车头的宽缺口」——宁可简单，也不给死局。

因此不只是「每排有空位」，而是**相邻两排之间来得及转过去**。
单测里有一个「称职玩家」：它只用和玩家一样的转向能力，朝最近一排通道里最省力的点走，
必须连续骑到 4 000 m 不撞（7 个种子）。

碰撞检测把**一帧走过的整段路**一起扫：先在障碍坐标系里求纵向重叠期，再在该时间段里查横向。
60 m/s 下一帧走 1 m、比墙还厚，也不会漏判（单测覆盖）。

## 四、状态、暂停与结算

阶段用明确状态机（`lib/machine.ts`）管理，互斥：

```
idle（待机）→ countdown（倒计时）→ running（行驶）
running / countdown ⇄ paused（暂停，含切后台自动暂停）
running / paused → spectator（旁观：暂停 + 自由飞）→ running / paused
running → crash（碰撞演出）→ result（结算）
任何阶段 restart → countdown
```

- **暂停、旁观、碰撞演出、结算期间，距离与分数都不增长**（单测覆盖）。
- 碰撞流程：撞击 → 短暂慢动作与镜头震动 → 卡通车翻 + 尘土 → `咔嚓` + X 光片 → 结算。
  演出约 2.4 s，可随时跳过（空格 / 按钮）。
- 结算显示距离、魔丸 GPA、9 的个数、历史纪录；按钮：**再来一次**、**返回展馆**，
  另有四件展品的入口（自行车变速 / 航空发动机 / GPA / 骨折原理）。
  查看科普是可选操作，不挡住重试。
- 结算文案：「距离满绩还差一点，距离骨折已经为零。」
- 历史最好成绩存在 `localStorage`（键 `thesecretofdesign.mowan.best.v1`），没有账号、没有服务器。

## 五、镜头与资源

- 默认追尾镜头：视野清楚，发动机、车身与特效都不挡前方障碍；高速与冲刺时视野略微拉宽。
- 旁观者模式与变速器展品同一套交互（指针锁定 + WASD），进入时暂停，退出后恢复跟随。
- 全屏是可选功能（HUD 右上的「全屏」，`Esc` 退出）。
- 离场释放：停帧循环、断开监听、`dispose()` 几何/材质/贴图/渲染器；标签页切后台自动暂停。
- 画质：按设备自动选「高 / 低」（触屏小屏默认低），暂停菜单可切换。低画质关阴影与顶棚、降像素比。

**坐标不漂移**：车辆永远在原点附近，路面与障碍按里程向后退。
道路装饰（路缘、标杆、树、楼、灯杆）用「里程取模」循环复用，不新建对象。

## 七、起点门楼

按用户提供的北航「体能锻炼走廊」实拍照片重建。照片里能认出来的东西都做了：

- 两根白色圆柱（柱脚墨绿钢箍）撑起整座门；
- 蓝色弧形顶棚是**左右两块分开**的阳光板，中缝压脊梁；板下两道墨绿弧形钢梁 + 五根檩条；
- 顶棚上方一道很扁的钢拱，八个金色大字一个个竖直装在拱上，高低跟着拱走；
- 两侧墨绿框钢板网围栏（上横杆、下横杆、三根立柱），挂「安全提示」「注意安全」两块牌子；
- 入口两扇墨绿框网格大门向内敞开；门内两侧不锈钢闸机，中间留出宽通道。

取舍：闸机只铺路面外侧，**不占用行车线**（否则等于给玩家一排隐形墙）；门楼是纯布景，不参与碰撞。
静态件按材质合并，整座门楼十来个 draw call；走远后整体隐藏。

尺寸是按照片比例目测的示意，**不是实测**，页面上不当作数据展示。

骑手头盔：北航蓝的盔体 + 一枚圆形校徽贴片（`public/mowan/beihang-logo.jpg`，运行时在 canvas 上加深一圈蓝边再贴）。
贴片是按球冠几何做的，UV 按「到圆心距离」重算，所以校徽贴在球面上不会被拉成方块；
朝向从「车身右侧 / 后上方」两组方向算出来，追尾镜头里字是正的。

开场与首页入口卡**不解释计分规则**：只写「分数会一直涨，但涨法有点怪」。
「每 500 m 多一个 9」是留给玩家的笑点，骑到 1 000 m 的节点门牌上才第一次露出来；
游戏页下方的「规则与说明」仍然完整写明规则（那是资料，不是开场白）。

## 八、验证与剩余限制

**单测**（`npm test`，共 250 项，其中魔丸模式 53 项）覆盖：计分节点与极长距离、
暂停/旁观/演出/结算不涨分、重启清空并保留纪录、扫掠碰撞不漏判、可达性与「称职玩家」4000 m 存活、
冲刺余量、后台自动暂停。

**浏览器实测**（1264×805 与 390×844 两种视口）：待机、倒计时、行驶、节点门牌与第 1 个 9、
暂停、旁观者模式、碰撞演出与 X 光片、结算（含四件展品入口）、长距离 `3.999999…`、
首页入口卡、`dist/` 生产构建。截图见 `.shots/mowan-*.png`。

剩余限制：

- 没有跳跃/飞行/联机/换挡；冲刺只是约两秒的加速。
- 按动圆珠笔还没做成车把上的启动键（彩蛋留到下一版）。
- 旁观者模式的指针锁定在受限容器里可能被浏览器拒绝，这时按住拖动也能环顾。
- 窄屏只做了布局与触控按钮实测，没有真机长时间性能测试。
- 开场背景照待补；现在开场背景是实时的三维跑道与门楼。
- 门楼、发动机、车架都是示意模型，不追求机构正确，也不加载完整展品页面。
- 在受限沙箱里 `npm run dev` / `npm test` / `npm run build` 可能报 `spawn EPERM`（Vite 会同步调用 `net use`），
  普通终端里不受影响。
