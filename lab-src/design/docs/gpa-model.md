# GPA 展品说明（模块 B）

记录这个展品的计算关系、规则来源、边界情况与数据存放方式。
页面上的每个数字、每段条形都来自 `src/exhibits/gpa/model.ts` 的同一个结果对象。

## 1. 计算模型

记号：c_i 学分、s_i 百分制成绩、g(s_i) 课程绩点、C 参与计算的总学分。

```
GPA   = Σ[c_i × g(s_i)] / C
w_i   = c_i / C                     学分权重，Σw_i = 1
q_i   = c_i × g(s_i) / C            加总贡献（单位是绩点），Σq_i = GPA
d_i   = c_i × [4 − g(s_i)] / C      满绩差距，Σd_i = 4 − GPA
ΔGPA  = c_i / C × [g(新) − g(旧)]   只改第 i 门、课程集合与学分不变时
```

三条容易混淆的规则，页面各处都照此处理：

- q_i 的单位是**绩点**，不是百分比，所以从不写成「占 GPA 的 x%」。
- 「当前贡献大」不等于「继续提分收益大」：收益还取决于分数落在曲线的哪一段。
- q_i（已经拿到的）与 d_i（还能拿到的）是两个视图，不混在一起。

中间计算全程用 `number` 原精度，只在显示时用 `fmtNumber` / `fmtDelta` 舍入。

## 2. 绩点规则

默认且唯一的预设：**北航本科换算公式（4.0 制）**

```
0 ≤ s < 60   : g(s) = 0
60 ≤ s ≤ 100 : g(s) = 4 − 3(100 − s)² / 1600
```

- 来源：北京航空航天大学教务部公开说明 <https://sge.buaa.edu.cn/info/1221/2957.htm>
- 只在页面上按这条公式计算，**不宣称**适用于所有年级、学院或全部课程。
- 通过/不通过、缓考、重修、五级制等特殊记分方式不套用；用户可以把该课程设为「不参与计算」，
  页面会提示按本人适用规则确定课程范围。
- 未逐条核对各年级、各学院的最新执行细则，这个缺口在页面的「待确认」段落里写明了。
- 规则写成了 `GradeRule` 配置（名称、公式、来源、适用范围、换算函数），
  以后加别的规则只需要往 `GRADE_RULES` 里加一项，不需要改计算与图表。

## 3. 输入与空值

课程记录里 `creditsText` / `scoreText` / `targetText` 都按**文本**保存，这是为了能区分：

| 输入 | 含义 | 处理 |
| --- | --- | --- |
| 成绩留空 | 未填写 | 该课程暂不参与计算，列表里保留，注明「缺成绩，暂不计入」 |
| 成绩 `0` | 有效成绩 | 正常参与计算，绩点 0，会拉低 GPA |
| 成绩 `101` / `abc` | 无效 | 不参与计算，注明原因；不会默默当 0 分 |
| 学分留空 / `0` / 负数 | 无效 | 不参与计算，注明原因 |
| 假设成绩留空 | 不改 | 按原始成绩计算，不产生 ΔGPA |
| 假设成绩 `105` | 超范围 | 截断到 100 后参与计算（页面会显示按 100 计） |

清空输入框时不会被强制改成 0：输入框直接绑定文本，解析交给 `parseCredits` / `parseScore`。

## 4. 提分实验

- 假设 GPA 把所有课程各自的假设成绩一起代入计算，`变化量 = 假设 − 原始`。
- 「各科分别提高 5 分」：一次只改一门，其他保持原始成绩；`toScore = min(100, s + 5)`，
  实际加分可能是 2 分而不是 5 分，页面显示实际加分与对应 ΔGPA，并按 ΔGPA 从大到小排序。
  它只回答「同样 +5 分对总 GPA 的影响」，不构成投入产出或学习时间建议。
- 课程学分或参与范围一变，分母 C 和所有 w_i、q_i、d_i 一起重算，不存在缓存。

## 5. 视图

| 视图 | 画什么 | 固定标尺 |
| --- | --- | --- |
| 学分权重 | 100% 分段条 + 每门课一行 | 0–100% |
| 当前贡献 | q_i 堆叠到 GPA，竖线标出总 GPA | **0–4 固定**，不随数据缩放 |
| 提分实验 | 原始/假设绩点与贡献、联合 ΔGPA、各科 +5 排行 | 行内条形按本视图最大值 |
| 满绩差距 | 浅色段 = 已获得 GPA，彩色段 = d_i | 0–4 固定 |

行内条形按「本视图最大值」等比缩放，数值一律同时写出，避免只靠条形长度读数据。
零贡献课程仍保留在列表与图例里。

## 6. 数据与隐私

- 课程保存在 `localStorage` 的 `thesecretofdesign.gpa.v1`，键值结构 `{ courses, sample }`。
- 首次打开、没有本地数据时载入示例数据并标「示例数据」，不会覆盖任何已有数据；
  示例课程来自用户提供的一份课程清单（工科数学分析 5 学分 90 分等 5 门），不对应任何学校或专业培养方案。
- 只要用户编辑一次，`sample` 变为 false，页面显示「已保存在本浏览器」。
- 导入前先校验：解析失败、结构不对、课程数超过 200 条都会拒绝，并保留原有数据。
- 导出为 JSON（含 app/version/exportedAt/sample/courses），导入导出往返后数据完全一致。
- 不上传、没有后端、不发任何网络请求。
- 刷新时若本地数据损坏：回到示例数据并提示「原数据未被覆盖」。

## 7. 导览

「带我看懂」使用独立的示例三门课（4 学分 80 分 / 2 学分 90 分 / 2 学分 60 分），
分五步讲：分数→绩点、学分→权重、加权求和、同样 +5 分的差别、满绩差距。
导览数据只存在内存里，不读写用户保存的课程；退出导览（点「退出导览」或页面上的「自由探索」）
回到用户自己的列表，编辑状态不变。

## 8. 简化与边界

1. 只实现一种绩点规则，没有做任意公式编辑器。
2. 不处理五级制、通过/不通过、重修取最高次等特殊口径，只提供「不参与计算」。
3. 不做学期 GPA、累计 GPA、排名、保研线之类的延伸。
4. 不生成任何学习建议或成绩预测。
