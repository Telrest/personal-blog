# 骨骼模块：显示修复与展示调整

2026-11-01，本轮仅修改骨骼展品及其专用样式、测试与说明，公开模型资源保持原样。

## 修复的问题

| 原问题 | 原因与修改 |
| --- | --- |
| 完整对照中小趾后两节消失 | 中节、末节被放在隐藏的骨折片段组下面。改为独立可见组，骨折时同步远端变换，完整时保持完整趾列。 |
| 受力和修复场景缺少参照骨 | 隐藏父组覆盖了子骨的显示规则。保留第 5 跖骨、近节、中节和末节四块骨，其他骨仅在局部实验中主动隐藏。 |
| 预设镜头只显示部分骨 | 按整个观察对象的八角包围盒同时计算横向与竖向取景；窄屏扩大竖向视角，局部默认保留完整第 5 趾列。重复选择同一镜头也可重新取景。 |
| 移动片段后剖切不对应，选中后剖切失效 | 完整骨、基底片段、远端片段分别持有材质与世界空间剖切平面；选中材质沿用同一裁剪关系。剖面与标注随片段移动。 |
| 断面可能只封住一部分 | 凹轮廓采用 Earcut 三角化；封口外圈保留裂面的微小起伏。 |
| 完整骨轴向受力看不到变化 | 原来只平移隐藏的骨折组。现在对可见完整趾列施加示意轴向变形，归零后恢复。 |
| 外展方向与箭头锥尖错误 | 外展方向改为模型 −X；箭杆与锥尖统一朝向，拉力箭头从趾尖向外。标签避开箭头。 |
| 骨痂采样不准确 | 用完整目标骨在模型空间做双面射线采样；把轴向范围限制在基底附近，避免跨出骨端生成悬空长壳。 |
| 修复过程未进入就走完、拖动后读数不更新 | 修复时钟只在修复页推进，默认暂停；去掉错误的无限通知时间，终点强制通知，完成后可再次播放。 |
| 全屏标签丢失 | 标签移到舞台内部，增加直接退出按钮。 |
| 场景目的不明确 | 新增整足定位、断端特写、受力实验、修复过程四个入口；模型旁显示当前目的、操作提示和剖切状态；一键恢复完整外形。 |

## 新的观察顺序

1. **整足定位**：完整 26 骨，识别橙色目标骨与灰蓝色跖骨。
2. **断端特写**：保留完整第 5 趾列，调整裂隙、横移、旋转，或对齐两片骨；主动开启剖切才移除一半外表面。
3. **受力实验**：跖骨为固定参照，箭头说明作用方向与相对强弱；载荷归零可比较形状。
4. **修复过程**：默认停住；直接点击血肿、软骨痂、骨性骨痂、重塑，或播放连续过渡。阶段按钮在模型下方与侧栏均可使用。

## 验证

- 骨骼专用测试 **48 项通过**。其中真实 GLB 回归检查完整 26 骨、三页签与完整/骨折切换、剖面跟随、选中后的剖切、真实顶点在最大断端姿态下的取景、箭头方向、轴向变形和标签跟随。
- 时钟测试检查暂停初态、拖动后的订阅通知、终点通知、大步长与不规则步长一致、非法步长、重播与重置。
- 桌面浏览器实际走完 10 步导览，检查四阶段、最大断端姿态与剖切、完整外形恢复、全屏标注、继续播放及重播。
- 390×844 窄屏检查：页面内容宽 375px，滚动宽同为 375px，无横向溢出；模型、受力箭头与说明可见。
- 全项目测试及生产构建通过；最终全项目共 250 项测试通过，骨骼专用 48 项通过。
- 没有在真实手机硬件、多个浏览器或长期 GPU 压力环境下测试。

实际预览图见 `bone-preview/`。沿用 BodyParts3D 来源与许可，详见 `bone-model.md` 和 `foot-model-attribution.md`。

## 仍然保留的简化

骨表面来自公开解剖数据；裂面、皮质厚度、松质纹理、受力形变和修复组织都是教学示意。没有真实髓腔、软组织约束、应力/断裂求解或个人恢复预测。局部实验隐藏无关骨是主动的隔离操作；页面注明当前对象，随时可以返回整足。

暂停的实际界面读数前后均为 2%；离开展品后画布数量为 0，重新进入可正常重建。
