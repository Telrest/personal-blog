# 按动笔模型说明（模块 A）

本文件记录这台按动笔展品的**依据、计算关系、状态设计与简化边界**。
改参数时请同时更新这里、`parameters`（`model.ts` 的 `PEN`）与展开图。

- 原型：**ZEBRA SARASA CLIP JJ15 0.5**，按动式凝胶墨水笔（不是油性圆珠笔）。
- 外观依据：用户提供的三张实物照片与一段视频（`E:\web\source\jj15-reference-pack-20261101`）。
- 官方名义尺寸（比例锚点，非精密测量）：

| 项目 | 值 | 来源 |
| --- | --- | --- |
| 全长 | 141.0 mm | ZEBRA 官方产品页（S01） |
| 轴径 | 11.0 mm | 同页 |
| 球珠直径 | 0.5 mm | 同页；只表示球珠，不是笔杆直径 |
| 笔芯 | JF-0.5，长 111.1 mm、最大直径 6.1 mm | ZEBRA 官方替芯页（S02） |

- 分段（教学轮廓）：透明前锥 0–11.5 mm，握胶 11.5–52，透明连接区 52–66，
  后透明笔杆 66–130.5，按帽 130.5–141（收芯）。

## 2. 机构：借鉴什么，自己定了什么

**借鉴的通用原理**（斑马 JP2007083498A 背景部分）：按杆推动转子沿导槽前进，
脱离约束后由斜面产生转动，释放时停在锁止位置，再次操作解除并回到导槽。
同系列拆解记录（S04）支持的零件组成：前部、复位弹簧、笔芯、后笔杆、按杆、回转子、笔夹。

**本项目的教学设定**（不是 JJ15 实物凸轮）：

| 参数 | 值 | 说明 |
| --- | --- | --- |
| 收芯位置 x_R | 0 mm | 机构位移基准，笔尖在壳内 0.8 mm |
| 出芯位置 x_E | 2.2 mm | 笔尖伸出 1.4 mm，按帽随之低 2.2 mm |
| 导向解除高度 x_clear | 4.0 mm | 凸耳离开导槽、可以转动的边界 |
| 完全按到底 x_max | 4.8 mm | 提交阈值 |
| 转子凸耳 | 3 个，相隔 120° | |
| 索引位置 | 6 个，相隔 60°，交替深／浅 | 深导槽 0/120/240°，浅锁止位 60/180/300° |
| 每次循环 | 60°（按下 30° ＋ 释放 30°） | 两次共 120°，三重对称下外观等价 |
| 弹簧 | 自由 18.0，装配 15.5，L(x)=15.5−x | 外径 4.2，线径 0.35，10 圈 |

**不做的**：不做接触求解、不做弹簧应力、不显示按压力。
`k = 0.25 N/mm` 只是可选的教学假设，页面没有采用。

## 3. 计算关系（唯一事实来源）

```
越往下 x 越大：
  笔尖轴向位置   Z = 0.8 − x          （0 → +0.8；2.2 → −1.4；4.8 → −4.0 mm）
  弹簧长度       L = 15.5 − x         （0 → 15.5；2.2 → 13.3；4.8 → 10.7 mm）
  弹簧压缩量     = 18 − L
  按帽顶端       Z = 141 − x
索引角：
  θ_base = 60 × cycle
  按下 4.0→4.8：θ = θ_base + 30 × (x−4.0)/0.8
  释放 4.8→4.0：θ = θ_base + 30 + 30 × (4.8−x)/0.8
  落到支承面：  θ = θ_base + 60
  未提交回退：  θ 沿按下那段原路退回（对称）
状态：
  cycle 偶数 → R（收芯，x=0）；奇数 → E（出芯，x=2.2）
  θ/60 的整数位 → 索引位序号；偶数位深导槽、奇数位浅锁止位
```

`model.ts` 的 `derivePose()` 是唯一实现，`model.test.ts` 与 `controller.test.ts`
对上面每一条都有断言（含 x=0/2.2/4.8 的三组笔尖 Z 与弹簧长度）。

## 4. 一次完整操作（与页面导览一致）

| 阶段 | x | θ | 说明 |
| --- | --- | --- | --- |
| ① 初始 | 0 | θ_base | 收芯；弹簧预压 2.5 mm，止挡是按帽轴肩 |
| ② 沿导槽推进 | 0 → 4.0 | 保持 | 凸耳被导槽夹住，只许直上直下 |
| ③ 脱离导向 · 索引 | 4.0 → 4.8 | +30° | 斜面把 0.8 mm 轴向行程换成 30° 转动 |
| ④ 回程斜面 | 4.8 → 4.0 | +30° | 另一侧斜面再转 30°，共 60° |
| ⑤ 落到支承面 | 4.0 → 2.2 或 0 | 保持 | 浅锁止面挡住 → 出芯；深导槽放行 → 收芯 |

## 5. 状态机与提交规则

```
idle ──press/drag──► pressing ──x>4.0──► indexing ──x≥4.8（committed）──►
                     releasing ──x<4.0 且已提交──► settling ──x 到静止位──► idle
                     aborting（x<4.8 就松手，θ 原路退回，状态不变）
```

- **提交阈值 = x ≥ 4.8**：只有按到底才切换。按到一半（4.0–4.8）松手会让索引角退回，
  状态保持不变——这是用状态机而不是时间函数实现的，单测覆盖。
- 拆解视图会暂停机构；回到装配后保留原状态。
- 导览「带我看懂」把模型摆到各阶段的静态快照，暂停、逐阶段看。

## 6. 直接操作（没有文字按钮也能用）

- 拖动空白处：旋转视角（用户动过之后不再自动回正）。
- 按住按帽往下拖：沿笔轴按压，行程直接进模型；松手由机构决定是否提交。
- 单击零件：选中并高亮，右侧显示一句用途。
- 透明外壳不挡拾取：点透明笔杆处会选中里面的零件；握胶这类实心件正常遮挡。

## 7. 简化边界（必须保留在页面说明里）

1. 内部是**简化教学机构**，不是 JJ15 的实物凸轮；齿形、间隙、行程可整体调整。
2. 只做运动学与索引拓扑，不做接触力、摩擦、弹簧应力、油墨流动。
3. 不显示按压力（没有可靠数据）。
4. 笔夹是独立演示，不影响锁止。
5. 视频未做逐帧分析，机构细节不是从视频量出来的。

## 8. 外形与展示细化（2026-11-01）

- 依据资料包 U01–U03 细化透明前锥、笔杆尾部收口、按帽圆角和握胶轮廓。
- 握胶以表面径向凹陷表现八组纵槽；槽深、数量和轮廓采样均是外观近似，不是实测加工尺寸。
- 笔夹加入轴向弧度、横向拱面、外侧支点和照片文字近似；不宣称铰接和弹片细节为厂家装配复刻。
- 透明塑料以视角相关的透明度和环境反光保留轮廓，无外部贴图依赖；连接区使用一条示意螺旋。
- 修正笔芯肩部：收芯时位于 Z=20.5，与弹簧后端一致；细颈延伸至此，避免粗笔芯管穿过弹簧。油墨起点相应后移。
- 弹簧按 L(x) 更新螺旋几何，压缩时不再沿轴整体缩放钢丝；不增加材料或接触力计算。
- 剖视统一打开前锥、握胶、连接区与导向；拆解时恢复零件完整形态。
- 增加笔夹、笔尖弹簧特写；机构导览自动切入剖视，窄屏单独适配镜头水平视野。
- 选中高亮使用分件材质；射线选择忽略不可见及已剖去的表面。
- 修正直接拖动的行程基准，避免从按帽中部拖动时突然跳到按到底；非画布点击和取消点击不触发按动。
- 动画跨帧时依次消费越过的状态端点，确保短暂卡顿不会漏掉到底提交；新增不规则帧间隔及单帧跨完整动作的回归验证。
- 拆解采用外壳径向抬起、内部轴向分开的展示布局，避免握胶和笔杆仍然套住笔芯与转子；径向偏移仅用于展示，不是装配运动。
